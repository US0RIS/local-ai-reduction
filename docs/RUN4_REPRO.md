# Run 4 controlled L2C reproducibility protocol

This document defines the current heavy benchmark protocol. Historical Run-1/2/3 JSON is retained for audit history but is not silently regenerated from current code; authority is recorded in `benchmarks/ARTIFACT_MANIFEST.json`.

## Environment

Recommended:

```bash
python -m pip install -e . pytest torch
```

The controlled model is CPU-friendly but training is intentionally excluded from quick CI. PyTorch/kernel version and CPU threading can cause small floating-point differences in NLL; structural byte counts must be exact.

## Full benchmark

Use an empty workspace:

```bash
rm -rf /tmp/larc-r4
python tools/run4_l2c_repro.py --workspace /tmp/larc-r4 --phase teacher
python tools/run4_l2c_repro.py --workspace /tmp/larc-r4 --phase convert
python tools/run4_l2c_repro.py --workspace /tmp/larc-r4 --phase q4-recover
python tools/run4_l2c_repro.py --workspace /tmp/larc-r4 --phase evaluate
cat /tmp/larc-r4/result.json
```

Or run `--phase all`.

### Phase definitions

1. **Teacher:** 16 independent Transformer blocks, 120 AdamW steps, LR `2e-3`.
2. **Structural conversion:** arithmetic mean of the 16 teacher block state tensors into one recurrent/shared physical block; 200 recovery steps, LR `1.5e-3`.
3. **Projected-Q4 recovery:** project every matrix to canonical `Q4_ROW` and every 1-D parameter to FP16; run 200 AdamW steps at `3e-4`; after every update immediately project back to the storage grid. Choose among 25-step checkpoints on a disjoint selection stream.
4. **Evaluation:** evaluate a separately Q4-projected teacher, the Q4-recovered shared model, and the shared model with deterministic latent-Q2 KV using E4M3-FN min/scale metadata and both K/V inverse-Gram metrics.

### Data separation

All text is generated from the same deliberately narrow grammar but independent PRNG streams:

- training: seed **3**,
- Q4-recovery checkpoint selection: **444**,
- latent-basis calibration: **555**,
- final 100,032-character evaluation: **333**.

The final evaluation stream is therefore not used for optimization, checkpoint selection, or compression-basis fitting.

### Current expected result

Approximately:

- Q4 teacher NLL: **1.88548**,
- Q4-recovered shared NLL: **1.94078**,
- Q4-recovered + latent-Q2/E4M3 metadata NLL: **1.97525**,
- total delta: **+0.08977 nats/char**,
- perplexity ratio: **1.09392x**.

At context 64 the structural byte model is:

- teacher Q4 weights: 1,129,482 B,
- shared Q4 weights: 77,322 B,
- baseline FP16 KV: 524,288 B,
- LARC Q2+FP8-metadata KV: 49,152 B,
- Q4 K/V bases plus both FP16 inverse-Gram metrics: 6,400 B.

Using the direct-packed attention scratch contract (`runtime/larc_q2_attention.cpp`) gives approximately **12.04x** modeled same-context tensor reduction. This is **not** measured process RSS/VRAM; it composes an L2C quality experiment with an independently validated L1 packed-attention runtime contract.

## Quick reproducibility checks

These are CI-safe and must match committed artifacts:

```bash
pytest -q
python tools/check_quick_benchmark_artifacts.py

g++ -O3 -std=c++17 runtime/larc_q4.cpp tests/native_q4_smoke.cpp -o /tmp/q4-smoke && /tmp/q4-smoke
g++ -O3 -std=c++17 runtime/larc_q4.cpp tests/native_q4_fidelity.cpp -o /tmp/q4-fidelity && /tmp/q4-fidelity
g++ -O3 -std=c++17 runtime/larc_q4.cpp runtime/larc_q2_attention.cpp tests/native_q2_attention.cpp -o /tmp/q2-attn && /tmp/q2-attn
```

`tests/native_q2_attention.cpp` validates direct packed-cache execution against a separately decoded mathematical reference. It does not claim optimized throughput.

## Historical artifact policy

An artifact generated by an older implementation is not evidence for current code merely because it remains in `benchmarks/`. Use `benchmarks/ARTIFACT_MANIFEST.json` to determine whether a file is current, historical, superseded, or revoked.
